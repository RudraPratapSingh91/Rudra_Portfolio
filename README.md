# 📁Rudra_Portfolio

This repository contains the source code for my professional portfolio website, designed and developed by me. It showcases my skills, projects, experience, and serves as a central hub for my technical journey.

## 🚀 Features

- **Modern Design**: Clean, professional, and responsive layout.
- **Interactive Elements**: Smooth animations, hover effects, and micro-interactions.
- **Full Page Sections**:
  - **Hero**: Introduction and call to action.
  - **About**: Personal background and technical philosophy.
  - **Experience**: Professional journey and roles.
  - **Skills**: Technical proficiencies and tools.
  - **Projects**: Showcase of key projects with details.
  - **Contact**: Easy ways to get in touch.
- **Navigation**: Sticky header, smooth scrolling, and mobile-friendly menu.

## 🛠️ Tech Stack

The portfolio is built using modern web technologies:

- **HTML5**: Semantic structure.
- **CSS3**: Custom properties (variables), flexbox, grid, animations.
- **JavaScript (Vanilla)**: Dynamic content, interactions, and helpers.

## 🔌 Installation & Setup

Since this is a static portfolio website, no complex installation is required.

### Local Development

1.  **Clone the repository** (or download the ZIP file).
2.  **Open `index.html`** in your web browser.

For a better development experience with live reloading, you can use a simple HTTP server:

**Using Python:**
```bash
cd Rudra_Portfolio
python -m http.server 8000
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.

**Using Node.js (if installed):**
```bash
cd Rudra_Portfolio
npx serve .
```
